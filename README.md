# pixel-focus
Telegram Mini App для учёта времени.

## Как проверить на компьютере
Откройте файл `index.html` двойным щелчком: он откроется в браузере. Ничего устанавливать не нужно.
Данные в браузере сохраняются в его памяти; в Telegram — в облаке Telegram.

## Структура
- `index.html` — страница приложения (не меняется при обновлениях)
- `loader.js` — номер версии и список файлов; при публикации увеличить VERSION
- `css/style.css` — оформление
- `js/util.js` — время, даты, форматирование
- `js/storage.js` — хранилище (Telegram CloudStorage / localStorage), нарезка на куски под лимиты
- `js/store.js` — данные и действия: занятия, записи, проверки, резервная копия
- `js/ui.js` — иконки, всплывающие окна, подсказки
- `js/i18n.js`, `js/i18n-en.js` — перевод (русский/английский)
- `js/char.js` — пиксельный персонаж и каталог вещей
- `js/screens/*.js` — вкладки (таймер, статистика, персонаж, задачи, настройки)
- `js/app.js` — запуск и нижняя панель
