# Автопроверки

Эти файлы не входят в само приложение (загрузчик `loader.js` их не подключает). Они нужны при разработке,
чтобы после каждого изменения быстро убедиться, что ничего не сломалось.

Нужны Node.js и Playwright с браузером Chromium (в облачной среде разработки они уже установлены).

| Команда | Что делает |
| --- | --- |
| `node tests/i18n-check.js` | Проверяет, что у каждой русской фразы есть английский перевод. |
| `node tests/shots.js <папка>` | Делает снимки всех основных экранов с тестовыми данными. Ключи: `--dark`, `--style=<стиль>`, `--scale=2`, `--view`, `--only=timer-active,shop`. |
| `python3 tests/diff.py <до> <после> [папка]` | Сравнивает две папки со снимками и показывает, где изображение изменилось. |
| `node tests/char-audit.js` | Проверяет рисунки персонажа без браузера: каждая вещь и 5000+ сочетаний (причёска + аксессуар, верх + штаны, штаны + обувь…). Ищет обрезку краем картинки, оторванные точки, просветы в силуэте, неверную привязку к части тела. |
| `node tests/char-sheets.js <папка> <набор>` | Листы с персонажами, чтобы посмотреть глазами: `items`, `hats`, `tops-pants`, `pants-shoes`, `dances`, `colors`. |
| `node tests/dance-clip.js` | В приложении останавливает каждый танец на каждом кадре и проверяет, что персонаж не обрезается рамками и не вылезает из карточек. |
| `node tests/contrast.js` | Проверяет читаемость надписей во всех стилях, в светлой и тёмной теме (контраст букв с фоном по снимку экрана). Ключи: `--style=pixel,neon`, `--dark`, `--light`, `--min=2.5`. |
| `node tests/motion.js` | С включёнными анимациями проходит по приложению в каждом стиле и ищет «застрявшие» невидимые элементы, ошибки и горизонтальную прокрутку. `--shots=<папка>` сохраняет кадры посреди анимаций. |

Перед публикацией стоит прогнать все проверки: `i18n-check`, `char-audit`, `dance-clip`, `contrast`, `motion`.

Как проверить, что правка не изменила внешний вид:

```bash
node tests/shots.js /tmp/before          # до правки
# ...правка...
node tests/shots.js /tmp/after
python3 tests/diff.py /tmp/before /tmp/after /tmp/diff
```

`tests/lib.js` — общие помощники: встроенный сервер для папки проекта, открытие приложения с фиксированным
временем (13 ноября 2026, 15:30 по Москве) и выключенными анимациями, наполнение тестовыми данными, список экранов
(`SCREENS`) для снимков и проверок.
